## Questionário

### 1. Qual é a diferença entre Working Directory, Staging Area e Repository?

O Working Directory é onde ficam os arquivos que estamos criando ou alterando no projeto.

A Staging Area é a área onde colocamos os arquivos que serão incluídos no próximo commit, utilizando o comando `git add`.

O Repository é onde ficam armazenados os commits e o histórico das versões do projeto.

### 2. Qual é a diferença entre git commit e git push?

O `git commit` salva as alterações no repositório local, criando um ponto de versão.

O `git push` envia os commits do repositório local para o repositório remoto, como o GitHub.

### 3. É possível realizar vários commits antes de executar um git push? Explique.

Sim. É possível realizar vários commits localmente antes de executar o `git push`. Todos esses commits ficam armazenados no repositório local e podem ser enviados juntos posteriormente para o GitHub.

### 4. Por que é interessante realizar commits pequenos e descritivos?

Porque facilita o acompanhamento do desenvolvimento e permite identificar com mais facilidade quais alterações foram realizadas em cada etapa do projeto.

### 5. O que acontece com os commits locais quando ainda não executamos o git push?

Os commits continuam armazenados no repositório local. Eles ainda não aparecem no repositório remoto do GitHub até que seja executado o `git push`.

### 6. Como verificar, pelo GitHub, se os commits foram enviados corretamente?

É possível acessar o repositório no GitHub e verificar o histórico de commits. Os commits enviados pelo `git push` deverão aparecer na lista de commits do repositório remoto.
