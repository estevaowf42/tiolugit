# MeuPrimeiroGit

Projeto inicial de uma aplicação web para uma pequena lanchonete.

## O que foi desenvolvido

Até o momento foram realizadas as seguintes etapas:

- Criação da estrutura inicial do projeto.
- Documentação da funcionalidade de produtos.
- Criação da página de produtos.
- Adição de estilização inicial com CSS.
- Criação da página de pedidos.
- Documentação da funcionalidade de pedidos.

## Estrutura do projeto

- `docs/` - Documentação do projeto.
- `src/` - Arquivos da aplicação web.
- `src/index.html` - Página inicial.
- `src/produtos.html` - Página de produtos.
- `src/pedidos.html` - Página de pedidos.
- `src/style.css` - Estilos da aplicação.
